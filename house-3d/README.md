# Raised ranch — three.js model

A 3D model of a brick raised-ranch house built from three street-level photos.

Open `index.html` directly in a browser (no server or build step; three.js r128
is vendored in `vendor/`). Use the buttons to jump to camera angles that roughly
match the reference photos, or drag / scroll / right-drag to explore.

All textures (brick, siding, shingles, grass, concrete) are drawn procedurally
on canvases in `js/main.js`.
