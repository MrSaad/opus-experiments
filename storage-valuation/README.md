# Storage in the AI era: SNDK · STX · WDC

An independent, filings-first analysis of whether Sandisk, Seagate and Western Digital are undervalued over the next 3–5 years. It tests the thesis that bigger AI models, bigger outputs and open-source proliferation drive storage demand.

**Open `index.html` in a browser.** No server, build step or internet connection is needed. All data and code are local.

```
index.html              the site (verdict, charts, exec-language analysis, company deep dives,
                        interactive valuation model, AI-video storage calculator, signposts)
assets/                 style.css, charts.js (dependency-free SVG charts), model.js (scenario model), app.js
data/data.js            every dataset the charts use (generated)
data/content.js         curated quotes, management targets, visibility timeline, company profiles
research/REPORT.md      the full written analysis
research/SOURCES.md     every filing and data URL
research/data/*.csv     the underlying datasets
research/scripts/       the code used to pull SEC XBRL, 8-Ks, 10-Ks/10-Qs, Form 4s, Hugging Face, Civitai and call keywords
```

As of Sept 25, 2026 (prices from the Sept 23 close). Not investment advice.
